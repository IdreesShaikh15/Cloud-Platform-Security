What do the numbers on these cards mean? (four separate things; there is deliberately no single combined "security score")
  • Workload trust (0-100): how much the agents trust this workload right now. It falls while they see something wrong, restarts at 0 when a workload is isolated, and has to climb back (20, 40, 60, 80) before each step back to normal access.
  • Agent trust (0-100): how much the other agents trust this agent's evidence (their median). It falls only when what an agent claims is contradicted by what the others see themselves. A low value marks it SUSPECT; a very low one means its votes are ignored.
  • Evidence confidence (0 to 1): how sure one agent is about one kind of signal (Network Activity, Running Processes, File Changes, Failed Logins) on one workload. 0 is normal.
  • Recovery Check: pass or fail, not a score. Before a replacement is accepted, the agents check that it is healthy, that its files match the known-good copy, that it behaves normally and that it is really a new instance.
  • Agreement Reached (3 of 4): an action such as Isolation happens only when at least 3 of the 4 agents have signed a vote for it. A missing vote is never approval.
