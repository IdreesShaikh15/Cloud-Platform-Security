# Paper source (IEEE journal format)

`main.tex` is the full paper (Sections I-VII, tables, figures, inline reference list). Build with
`pdflatex main.tex` twice; it needs `IEEEtran`, `cite`, `booktabs`, `tabularx`, `graphicx`, `amsmath`.

**It has not been compiled** (no LaTeX in the environment where it was written). Expect to fix small things
(float placement, a table width) on the first Overleaf build.

Figures (`figs/`):
- `fig1_architecture.pdf`, `fig2_workflow.pdf`: vector, generated by `docs/paper-figures/make_figures.py`. Fig. 2 is tall, so it is set at 78% of the text width; if you want it smaller, re-lay it out wider.
- `fig3_testbed.pdf`: testbed diagram (same generator). `timing.png`, `trust.png`, `mixed.png`, `baselines.png`, `faulttol.png`, `dvc.png`: copies of `results/fig1`, `fig2`, `fig8`, `fig9`, `fig5`, `fig3` (simulator results, created by `scripts/evaluate.py`).
- `live.png`: crop of the Live Monitoring screenshot from the authors' own cluster (page 25 of the screenshots PDF).

Before submission:
- Fill in the author-contributions sentence in the Declarations.
- Check every reference (authors, pages, DOIs); they were written from memory and not looked up online. Refs [12] (Jarkas et al.) and [25] (Synthea) in particular.
- Numbers in the Results come from `docs/RESULTS.md`, `docs/SANDBOX-CLUSTER.md` and the dashboard screenshots; re-run `scripts/evaluate.py` if you change anything.
